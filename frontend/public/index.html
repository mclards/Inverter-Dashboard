                    Before you flash — safety checklist
                  
                  
    
                    
  1. STOP the inverter — it must NOT be running or grid-connected. The DSP refuses firmware-load mode while the unit is online.
    2. 
                    
  2. Clear the bus on every PC, not just this one. Close ISM, any SCADA/DAS, and every other dashboard or poller — including instances on other PCs on the LAN. The built-in lock only suppresses pollers on this PC.
    3. 
                    
  3. Disable the whole inverter IP on those other dashboards, not a single node. Every node behind one gateway shares one RS-485 bus, so polling any node on the same IP keeps the bus busy.
    4. 
                    
  4. Verify with Read Identity that the node, serial, and current firmware match the unit you intend to flash.
